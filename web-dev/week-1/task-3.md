## Task Description
Build a responsive project showcase grid using CSS Grid.

## Requirements
- At least 6 project cards
- Each card has: project image/icon, title, description, and a "View Project" link
- Uses CSS Grid (not flexbox) for the layout
- Grid auto-adjusts: 3 columns on desktop, 2 on tablet, 1 on mobile

## Acceptance Criteria
- [ ] CSS Grid is used (verify with DevTools)
- [ ] Cards are responsive without any media-query breakpoint hacks
- [ ] Cards have a hover effect (e.g. lift with `transform: translateY(-4px)`)
- [ ] Images/icons have proper alt text for accessibility
