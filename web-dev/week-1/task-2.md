## Task Description
Create an engaging hero section for your personal portfolio landing page.

## Requirements
- Full viewport height (`min-height: 100vh`)
- Large, bold headline (your name + tagline)
- Subtitle text and a prominent Call-to-Action (CTA) button
- Background: a gradient or a subtle pattern (no plain white/black)
- CSS entrance animation: elements fade in or slide up on page load

## Acceptance Criteria
- [ ] Hero fills the full viewport height
- [ ] Headline uses a Google Font (e.g. Inter, Poppins, Raleway)
- [ ] CTA button has a hover effect
- [ ] At least 2 elements use a CSS `@keyframes` animation
