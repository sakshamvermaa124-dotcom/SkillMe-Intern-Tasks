## Task Description
Build a fully responsive navigation bar for a portfolio website.

## Requirements
- Use semantic HTML (`<nav>`, `<ul>`, `<li>`, `<a>`)
- Logo/brand name on the left, nav links on the right
- Uses flexbox for layout
- Hover states with smooth color transitions on all links
- Collapses into a hamburger menu on screens < 768px (with working toggle)

## Acceptance Criteria
- [ ] Navbar is sticky (stays at top on scroll)
- [ ] Hamburger menu works on mobile
- [ ] No horizontal scroll on any screen size
- [ ] Hover animations are smooth (use `transition`)
