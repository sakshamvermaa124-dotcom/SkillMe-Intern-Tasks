## Task Description
Conduct a thorough code review on a peer's portfolio repository.

## Requirements
- Review the code quality, accessibility, and performance of a peer's work
- Submit your review as a GitHub Issue on their repository
- Your review must be constructive, specific, and actionable

## Review Checklist
- [ ] HTML semantics: Are the right elements used for the right purpose?
- [ ] CSS: Are there magic numbers? Is it maintainable?
- [ ] JavaScript: Is there any repeated code that could be a function?
- [ ] Accessibility: Images have alt text, form fields have labels?
- [ ] Performance: Are large images uncompressed? Unnecessary libraries loaded?
- [ ] UX: Is the portfolio easy to navigate? Is the content clear?

## Acceptance Criteria
- [ ] Review is submitted as a GitHub Issue (not just a comment)
- [ ] At least 5 specific, actionable pieces of feedback
- [ ] At least 2 positive highlights (what they did well)
- [ ] Feedback is respectful and professional
