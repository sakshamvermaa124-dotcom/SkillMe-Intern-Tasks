## Task Description
Deploy your complete portfolio to a live URL using GitHub Pages or Netlify.

## Requirements
- The entire portfolio (all weeks' work) is available at a public URL
- Custom domain configured (optional, bonus marks)
- All links and images work on the live site (no broken references)
- HTTPS is enabled

## Acceptance Criteria
- [ ] Live URL is included in your PR description
- [ ] All features built in weeks 1-3 work on the live site
- [ ] The `<title>` and meta tags are correct on the live site
- [ ] No 404 errors for assets (images, CSS, JS)
- [ ] Bonus: Custom domain set up and CNAME configured

## Submission
Include the live URL and a screenshot of the homepage in your PR description.
