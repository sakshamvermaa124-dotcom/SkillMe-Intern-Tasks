## Task Description
Analyze a real-world dataset using Pandas and generate insights.

## Requirements
- Download a CSV dataset from [Kaggle](https://www.kaggle.com/datasets) or use the provided dataset link
- Perform exploratory data analysis (EDA): shape, dtypes, missing values, basic stats
- Answer at least 5 specific questions about the data using Pandas queries
- Generate at least 2 charts using `matplotlib` or `seaborn`

## Acceptance Criteria
- [ ] Jupyter Notebook or Python script with clear comments
- [ ] Missing values are identified and handled (not ignored)
- [ ] Each question is answered with a Pandas operation + printed result
- [ ] Charts have titles, axis labels, and are saved as PNG files
- [ ] `requirements.txt` or `pyproject.toml` is included
