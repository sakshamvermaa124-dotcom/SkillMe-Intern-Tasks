## Task Description
Write a detailed technical blog post about something you built during this internship.

## Requirements
- Minimum 800 words
- Topic: One of the projects you built in weeks 1-3
- Must include: problem statement, your approach, code snippets, what you learned
- Publish on [Dev.to](https://dev.to/) or [Hashnode](https://hashnode.com/)

## Acceptance Criteria
- [ ] Post is published publicly (include the URL in your PR)
- [ ] At least 3 code snippets with syntax highlighting
- [ ] Includes at least one diagram or screenshot
- [ ] Has a clear introduction, body, and conclusion
- [ ] Tags are set correctly (python, webdev, etc.)
- [ ] Bonus: Post gets at least 3 reactions (share it!)
