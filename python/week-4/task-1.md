## Task Description
Build and deploy a complete, full-stack Python web application.

## Requirements
- Backend: FastAPI with at least 5 API endpoints
- Database: PostgreSQL (cloud) or SQLite with SQLAlchemy
- Frontend: Simple HTML/CSS/JS frontend served by FastAPI
- Deployed to a free cloud platform (Render, Railway, or Heroku)

## Acceptance Criteria
- [ ] App is live at a public URL (include in PR)
- [ ] All features work on the live deployment
- [ ] Environment variables used for all secrets (no hardcoded keys)
- [ ] `README.md` includes: project description, setup instructions, live URL
- [ ] Basic authentication implemented (at minimum, an API key)
- [ ] Bonus: Automated tests with `pytest` for at least 3 endpoints
